- 更新前请先导出数据：设置 → 关于 → 导出数据。
- 更换了便签编辑器。输入时直接显示 Markdown 格式，只在光标所在的位置显示语法符号。
- 更新后可将旧编辑器保存的便签转换为新格式，转换前需先导出备份。
- 新增 GitHub 警告块，例如 `> [!NOTE]` 和 `> [!WARNING]`，显示为带颜色的标题。
- 新增快捷键：切换任务列表、在无序和有序列表之间切换、把标题变回正文。
- 点击表格单元格时会编辑表格的源文本。
- 便签和设置中的错误改为在对话框中显示；窗口显示失败时会出现「重新加载」和「关闭」。
- 关于页新增「反馈」按钮，会打开 GitHub issue 页面，并填好版本和系统信息。
- 便签文件夹位于其他位置时，导出数据将包含其中的便签。
- 提高了浅色和深色主题中次要文字的对比度。
